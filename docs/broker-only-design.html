Computer Use Broker-only 设计规格

目标：让 Claude Code 与 Cursor 通过官方 Codex Computer Use 运行时稳定操作 macOS 应用。

决策

仓库不再复制、修改、重签名或注入 OpenAI 的 Computer Use app。仓库提供一个透明 MCP 代理，以官方 codex mcp-server 作为受信任执行边界。

Claude Code / Cursor | v stdio MCP codex-computer-use-mcp | v inject runtime bootstrap, otherwise passthrough official codex mcp-server | v node_repl -> computer-use-client.mjs -> @oai/sky

代理职责

范围行为
插件发现从环境变量、Codex 插件缓存、临时 bundled marketplace 和 Codex.app 中发现当前版本的 computer-use-client.mjs，不写死版本号。
codex保留调用方已有 developer instructions，并追加无条件、幂等的 setupComputerUseRuntime() bootstrap。
codex-reply在续聊 prompt 前加入短恢复提示，避免持久 REPL 中错误的 globalThis.sky 阻止恢复。
协议JSON-RPC 请求、响应、通知、进度与 MCP Elicitation 双向透传；只改写上述两个工具调用和工具发现说明。
生命周期父进程 EOF、信号或异常时关闭并回收子 codex mcp-server，不创建 daemon。
失败模式找不到 Codex CLI 或官方 wrapper 时立即给出明确错误，不回退到旧二进制 hack。

安装与配置

install.sh 仅安装一个 Python 3 单文件代理到用户目录，并幂等合并以下配置：

客户端配置位置键
Claude Code~/.claude.jsonmcpServers.codex-computer-use
Cursor Agent~/.cursor/mcp.jsonmcpServers.codex-computer-use
Cursor GUI~/Library/Application Support/Cursor/User/settings.jsonmcp.servers.codex-computer-use

合并必须保留其他 MCP 和设置；内容未变化时不重写文件。卸载只移除由本工具管理且命令路径匹配的条目。

移除的旧表面

删除 NOP patch、TCC.db 直接写入、codesign、DYLD hook、复制官方 app、turn-ended notify 和旧 cua-cli。

因此 issue #3 至 #16 的问题面被结构性删除；issue #1 通过官方 Codex broker 身份边界解决，而不是继续绕过 sender authentication。

验收

层级证据
单元插件版本选择、请求注入、原指令保留、工具描述、配置合并与卸载。
协议假 MCP 子进程验证 Elicitation 往返、无关消息透传、EOF 回收。
官方直连当前 bundled skill bootstrap 后读取并操作 Calculator。
Claude Codeclaude -p 经新代理完成不同算式并重新读取结果。
Cursorcursor-agent -p 经新代理完成不同算式并重新读取结果。
非目标：不绕过 macOS TCC，不自动接受所有应用权限，不修改 Codex 插件缓存，不承诺第三方客户端自身不支持的 MCP 能力。
